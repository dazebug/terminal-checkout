Terminal Checkout Settings

Terminal

명령을 실행할 터미널 앱을 선택합니다.

Command Buttons

PR 페이지 브랜치 옆에 표시할 버튼 (최대 3개). Emoji가 버튼 모양이 되고, Label은 그 버튼에 마우스를 올렸을 때 나오는 툴팁입니다. Preset을 고르면 아래 세 칸이 해당 템플릿으로 채워집니다.

Command에서 쓸 수 있는 변수: {repo}, {branch}, {main}, {branch_underbar} (branch의 /를 _로 치환)

버튼은 최대 3개까지 추가할 수 있습니다.

Default Main Branch

글로벌 기본 main 브랜치. PR 페이지에서 base branch 감지가 안 될 때 사용됩니다.

Per-Repo Main Branch Override

특정 리포의 main 브랜치를 오버라이드합니다. 이 설정은 PR 페이지 base branch 감지보다 우선합니다.

Repository Main Branch
등록된 오버라이드가 없습니다.
